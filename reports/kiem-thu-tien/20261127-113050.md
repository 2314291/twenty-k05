## Lệnh tái hiện (ca LỆCH và QUAN SÁT)

Đặt khoá trước: PowerShell `$env:TWENTY_API_KEY="..."` (dùng `curl.exe`), bash `export TWENTY_API_KEY=...`.

**P4-01 opportunities** (QUAN SÁT, trả 201): batch 0 bản ghi

```bash
curl -s -X POST "http://localhost:3001/rest/batch/opportunities" -H "Authorization: Bearer $TWENTY_API_KEY" -H "Content-Type: application/json" -d '[]'
```

**P4-06 opportunities** (LỆCH, trả 400): object thay vì mảng

```bash
curl -s -X POST "http://localhost:3001/rest/batch/opportunities" -H "Authorization: Bearer $TWENTY_API_KEY" -H "Content-Type: application/json" -d '{"name":"x"}'
```

**P4-07 opportunities** (LỆCH, trả 400): mảng có phần tử sai kiểu (name=123), null và chuỗi
