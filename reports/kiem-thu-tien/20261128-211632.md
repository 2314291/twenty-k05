## Lệnh tái hiện (ca LỆCH và QUAN SÁT)

Đặt khoá trước: PowerShell `$env:TWENTY_API_KEY="..."` (dùng `curl.exe`), bash `export TWENTY_API_KEY=...`.

**P4-01 notes** (QUAN SÁT, trả 201): batch 0 bản ghi

```bash
curl -s -X POST "http://localhost:3001/rest/batch/notes" -H "Authorization: Bearer $TWENTY_API_KEY" -H "Content-Type: application/json" -d '[]'
```

**P4-06 notes** (LỆCH, trả 400): object thay vì mảng

```bash
curl -s -X POST "http://localhost:3001/rest/batch/notes" -H "Authorization: Bearer $TWENTY_API_KEY" -H "Content-Type: application/json" -d '{"title":"x"}'
```

**P4-07 notes** (LỆCH, trả 400): mảng có phần tử sai kiểu (title=123), null và chuỗi

